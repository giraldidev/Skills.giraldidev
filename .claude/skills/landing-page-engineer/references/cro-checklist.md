# Checklist de CRO (otimização de conversão) — revisão final

Rode antes de entregar. Cada item marcado aumenta a chance de conversão.

## Acima da dobra
- [ ] Em 5s dá pra entender: o que é, pra quem, por que importa, o que fazer.
- [ ] Headline foca no benefício/resultado, não na empresa.
- [ ] CTA primário visível sem rolar, com cor de destaque.
- [ ] Visual do produto real presente (não só ilustração genérica).
- [ ] Sinal de confiança/prova social já aparece.

## Mensagem & copy
- [ ] Fala com "você"; benefícios > features.
- [ ] Específico e com números, não genérico.
- [ ] As 3–5 maiores objeções estão respondidas (na copy ou FAQ).
- [ ] CTA com verbo + valor; nada de "Enviar/Saiba mais".

## Estrutura & foco
- [ ] Um único objetivo de conversão; sem links de fuga/menu que distrai.
- [ ] CTA repetido a cada ~1–1.5 telas, mesmo texto/ação.
- [ ] Prova social forte (depoimentos com rosto/nome/número, logos).
- [ ] Pricing claro com plano recomendado destacado (se aplicável).
- [ ] CTA final de fechamento com reforço de garantia.

## Confiança & risco
- [ ] Garantia/política/segurança visíveis.
- [ ] Microcopy de baixo risco perto do CTA ("sem cartão", "cancele quando quiser").
- [ ] Urgência/escassez, se usada, é real.

## Formulário
- [ ] Pede o mínimo de campos necessários.
- [ ] Validação inline, estado de loading, confirmação de sucesso.
- [ ] Acessível (labels, foco, erros anunciados).

## Performance (Core Web Vitals)
- [ ] LCP < 2.5s, CLS < 0.1, INP < 200ms (testado no mobile).
- [ ] Imagens otimizadas (AVIF/WebP, srcset, dimensões definidas, lazy).
- [ ] Fontes com swap/preload; JS de terceiros diferido.
- [ ] Lighthouse mobile ≥ 90.

## SEO & compartilhamento
- [ ] title + meta description com a UVP.
- [ ] Open Graph + imagem OG 1200×630 testados.
- [ ] Um h1, semântica correta, alt nas imagens.
- [ ] Schema/JSON-LD quando aplicável; indexação correta.

## Mobile & acessibilidade
- [ ] Mobile-first; alvos de toque ≥ 44px; sem scroll horizontal.
- [ ] Contraste AA; navegável por teclado; reduz motion respeitado.

## Medição
- [ ] Eventos instrumentados: pageview, scroll, clique CTA, submit, conversão.
- [ ] Tela/evento de obrigado dispara a conversão.
- [ ] Estruturado para A/B test do que tem maior alavancagem (headline/hero/CTA).

## Teste final
- [ ] Percorri a página inteira no mobile como um visitante cético.
- [ ] Testei o form de ponta a ponta (sucesso e erro).
- [ ] Conferi pior caso: texto longo, conexão lenta, JS desligado.
