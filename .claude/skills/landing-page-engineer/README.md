# landing-page-engineer

Skill de Claude Code que faz o assistente atuar como **engenheiro de growth +
copywriter + dev front-end de performance**, construindo landing pages que
**convertem** — não apenas páginas bonitas.

## O que ela resolve

Landing page tem um objetivo diferente de UI genérica: levar um visitante
cético a realizar **uma** ação. A skill cobre o caminho completo — estratégia
de oferta, copy persuasiva, estrutura de seções, performance, SEO e tracking —
sempre apontando tudo para o CTA.

## Quando é ativada

Pedidos para **criar, revisar ou otimizar**: landing pages, páginas de vendas,
páginas de captura, lançamento de produto/SaaS, waitlist ou squeeze pages — em
qualquer stack (Next.js, Astro, React, HTML/Tailwind, etc.).

Também pode ser chamada manualmente: `/landing-page-engineer`.

## Como funciona (workflow)

1. **Estratégia** — objetivo de conversão, público, oferta, UVP, objeções.
2. **Copy primeiro** — headline, subhead, benefícios, CTA (antes do design).
3. **Estrutura de seções** — hero → prova social → problema → solução → benefícios → features → depoimentos → pricing → FAQ → CTA final.
4. **Implementação** — mobile-first, performance (Core Web Vitals), SEO, captura e tracking.
5. **Otimização & medição** — eventos, A/B test, checklist de CRO.

## Princípios centrais

- Uma landing = **um objetivo, uma ação**. Sem links de fuga.
- Clareza vence esperteza; benefício vence feature.
- Performance é conversão (Core Web Vitals).
- Prova social cedo e sempre; reduza fricção e risco percebido.

## Relação com `ui-ux-pro-max`

Esta skill foca em **conversão**; usa a `ui-ux-pro-max` para a camada de
qualidade visual e acessibilidade. Use as duas juntas para resultado completo.
